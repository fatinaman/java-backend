Varibales : variables are used to store values and in java we need to mention the type of varaible beforehand so that we know how much space is needed for that variable.

Most commonly used primitive data types are :
-int
-double
-long
-char
-boolean

Literals : fixed values which are written directly in code are called literals

System.out.printf() - prints out a formatted string
common format specifiers are :
%s - string
%f - double/float
%.2f - decimal with 2 digits
%c- character
%b - boolean
%n - newline
