Source Code : Source code is something written by the programmer that is human readable and in case of the java programming language written as and saved as .java files.

The JAVAC compiler : The javac compiler is the java programming languages compiler that takes in a .java (source code) file and outputs a .class (bytecode) file. This byte code is runnable by the jvm.

JVM : JVM means the java virtual machine that is a virtual computer inside our computer that can run java programs

JRE : The java runtime environment includes a JVM and addtional libraries that allows user to run Java Applications only.

JDK : JDK or the java development kit includes the JRE and JVM along wite the compiler, debugger and additional tools. This lets the programmer write, test and debug java code.
